# GLM 5.1

**Type:** LLM (open-source)  
**Developer:** Z.AI (Zhipu AI)  
**Release date:** 27 March 2026  
**License:** MIT (HuggingFace: `zai-org/GLM-5.1`)  
**Model sizes:** Full-size (exact params not specified)  
**Key achievement:** First open-source model to surpass all proprietary models on SWE-Bench Pro (score 58.4) beating GPT-5.4, Claude Opus 4.6, Gemini 3.1 Pro.

**Compatibility:** vLLM, SGLang, KTransformers  
**Hardware targets:** Optimized for local inference (NVIDIA GPU, potentially CPU offload via KTransformers)

**Significance for on-premise deployment:**
- Enables on-premise agent capabilities at Opus 4.6 level without cloud dependency
- MIT license allows commercial embedding in physical boxes
- Performance parity shifts value proposition: local > cloud for cost+privacy
