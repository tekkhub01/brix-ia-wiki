## CtxPort — estensione open-source per portabilità del contesto AI (nicepkg)

**Source:** https://github.com/nicepkg/ctxport
**Author:** nicepkg
**Type:** Open-source browser extension (Chrome MV3) per la portabilità delle conversazioni AI
**Category:** AI tooling, context transfer, browser extension, productivity

---

### Overview

CtxPort copia intere conversazioni da servizi AI in un "Context Bundle" — documento Markdown strutturato con frontmatter — con un click, per incollarlo in un altro AI, nei propri appunti o in una PR. Zero upload, 100% locale, open source (MIT).

Segnalato via un canale Telegram di aggregazione news AI il 2026-08-21 (lingua originale: russo). Repository GitHub verificato il 2026-08-23 (HTTP 200).

### Piattaforme supportate
ChatGPT, Claude, Gemini, DeepSeek, Grok, Doubao (豆包), GitHub (Issues & PRs)

### Funzionalità
- In-Chat Copy Button (copio l'intera thread)
- Sidebar List Copy (copio dalle conversazioni nella sidebar senza aprirle)
- Keyboard Shortcut Alt+Shift+C
- Multiple Formats: Full, User Only, Code Only, Compact
- Frontmatter metadata (source, url, title, date, nodes, format)
- 100% locale, zero upload, nessun account, funziona offline

### Stato (2026-08-23)
- Chrome Web Store release: in arrivo
- Firefox support: in arrivo

- Batch export (selezioni multiple): in sviluppo
