# Introducing Claude Design by Anthropic Labs

## Overview

Claude Design is a new Anthropic Labs product enabling collaboration with Claude to create polished visual work: designs, prototypes, slides, one-pagers, and interactive mockups.

**Powered by:** Claude Opus 4.7 (most capable vision model)
**Availability:** Research preview for Claude Pro, Max, Team, Enterprise subscribers
**Rollout:** Gradual throughout day of launch

---

## Problem Statement

### Designer Constraints
- Experienced designers must ration exploration due to time constraints
- Limited prototyping of design directions (typically 2-3 instead of 10+)

### Non-Designer Barrier
- Founders, product managers, marketers with ideas but no design background
- Creating and sharing visual concepts is daunting without expertise

### Gap
- Slow feedback loops between brief → mockup → review → refinement
- Prototype creation (especially interactive) requires code review, PRs, technical infrastructure

---

## Key Features

### 1. Design System Integration
- Claude reads team's codebase + design files during onboarding
- Automatically builds design system (colors, typography, components)
- Every project thereafter uses team's branding automatically
- Multiple design systems supported per team
- System can be refined over time

### 2. Multi-Source Input
- Start from text prompt
- Upload images, documents (DOCX, PPTX, XLSX)
- Point Claude at codebase (auto-import design tokens)
- Web capture tool: grab elements directly from live website for realistic prototypes

### 3. Granular Refinement Controls
- **Inline comments** on specific design elements
- **Direct text editing** in designs
- **Adjustment knobs**: live tweaking of spacing, color, layout
- **Batch apply**: Claude applies edits across full design
- Natural conversation flow for iteration

### 4. Collaboration & Sharing
- Organization-scoped sharing
- Privacy levels: private, link-share (view-only), edit access
- Multi-person editing with shared Claude conversation
- Group brainstorming in real-time

### 5. Export & Handoff
- **Internal URL**: share within organization
- **File export**: folder download
- **Third-party exports**: Canva, PDF, PPTX, standalone HTML
- **Claude Code handoff**: package design + intent for seamless developer handoff

### 6. Advanced Capabilities
- Code-powered prototypes (voice, video, shaders, 3D)
- Built-in AI features
- Interactive prototype generation from static mockups
- No code review / PR required
