### Cos'è
**icons0** è un motore di ricerca icone open-source, ottimizzato sia per uso umano che per AI agent. Offre accesso a **200k+ icone** provenienti da **150+ collezioni open-source** (223 collezioni al momento del crawl).

### Funzionalità principali
- **Ricerca rapida:** interfaccia web minimale con ricerca testuale, filtraggio per collezione, categoria e licenza
- **MCP Server:** integrazione nativa per AI coding agent — consente di cercare e installare icone direttamente dall'IDE
- **Installazione via shadcn:** `npx shadcn@latest add @icons0/<collection>/<name>`
- **Dark mode nativa**
- **Powered by Iconify** sotto il cofano

### Collezioni principali (sample)
